# Instructions pour Claude

## Design / UI

Pour toute modification visible du site (page, composant, couleurs, typographie, layout, animation, copy d'interface) :

1. Invoquer le skill `ui-ux-pro-max` (via l'outil Skill) avant d'écrire le code, pour les recommandations de style, palette, typographie et patterns de page.
2. Appliquer aussi les skills de design déjà installés (`emil-design-eng`, `apple-design`, `ui-styling`, `design-system`) selon le besoin.
3. Vérifier en fin de travail : contraste, états hover/focus, responsive (375 / 768 / 1024 / 1440 px), `prefers-reduced-motion`, pas d'emojis en guise d'icônes.

Ne pas attendre une demande explicite : c'est la façon par défaut de travailler sur ce projet.
